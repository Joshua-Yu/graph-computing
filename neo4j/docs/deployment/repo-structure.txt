Conventions
-----------
- "Party" is the canonical graph term (model/, cypher/, src/). "Customer" is kept
  only where it mirrors a source system's own name (data-contracts/). The mapping
  is defined once, in docs/01-overview/glossary.md.
- cypher/migrations/ is the only executable source for constraints and indexes.
- Risk scoring lives in src/risk/scoring/; Hume workflows in orchestration/hume/workflows/.
- Graph and Cypher tests both live in tests/graph/.
- data-contracts/schemas/ holds one format only: the one the Kafka schema registry uses.
- test-data/ and notebooks/ are synthetic data only; notebook outputs are stripped
  before commit (.pre-commit-config.yaml).
